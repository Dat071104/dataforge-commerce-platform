# Screenshot plan · authentic evidence only

No screenshots are generated by this plan. Capture a screen only from the real application and current evidence source; otherwise present the static receipt. Existing P6.2 screenshots remain the only screenshots already stored for this portfolio.

| Candidate screen | Evidence source | Capture condition | Redact / avoid |
|---|---|---|---|
| High-level architecture | Open [editable diagrams.net source](../../architecture/dataforge_overview.drawio) in diagrams.net and capture the rendered actual diagram. | Capture after the editable file is opened and labels/arrows are visible. | Do not paste a reconstructed or AI-rendered diagram and call it a screenshot. |
| Power BI report | Existing images in [v1.0-local screenshots](../../screenshots/v1.0-local/). | These are retained screenshots from the actual local report; point to the files or take a fresh capture from Power BI Desktop. | Do not claim a live Power BI Service deployment; no Service publishing is recorded. |
| Week 4 GCS/BigQuery | [Week 4 transfer and rerun receipts](../../cloud/evidence/). | Capture Console only if the current read-only identity can access the exact retained project resources. Otherwise show the checked-in receipt. | Hide personal account/email, project number if unnecessary, browser profiles, and unrelated projects. |
| Week 5 checkpoint / failure recovery | [Week 5 acceptance matrix](../../cloud/week5/acceptance_matrix.md) and incident snapshots. | Prefer the verified ledger/receipt files; Console access is optional and read-only. | Do not run an extra job to recreate a failure or publish a new batch. |
| Week 6 Spark plan / UI | [Benchmark](../../cloud/week6/benchmark.md), physical plans and [Spark UI evidence note](../../cloud/week6/spark_ui_evidence.md). | No Spark UI screenshot is currently claimed. Capture only if an actual local Spark UI is available from a rerun the user explicitly chooses. | Never fabricate Spark UI panels or use a static diagram as UI evidence. |
| Week 7 dbt lineage / Gold | [Model lineage](../../cloud/week7/model_lineage.md), [acceptance matrix](../../cloud/week7/acceptance_matrix.md), and receipts. | Use retained dbt artifacts or a current read-only view if available. | Avoid a new billed query, candidate corruption, publication, or Workflow execution. |
| Mini3 BigQuery weather row | [API-to-Gold receipt](../../cloud/week7/closure/api_to_gold_e2e_receipt.json). | Prefer the exact receipt; only use Console if current read-only access is already available. | Do not imply more than one observation date / three rows. Do not execute an uncapped query. |
| Airflow DAG and run | [Airflow integration record](../../cloud/week7/closure/airflow_integration_receipt.md) and the current DAG source. | A static receipt is the fallback; no current Airflow UI/scheduler is claimed. | The historical sensor task is not a screenshot of async waiting. Do not show credentials or run a new cloud operation. |
| SCD2 history | [dbt SCD2 receipt](../../cloud/week7/closure/dbt_scd2_history_receipt.json). | Use the actual receipt unless the mentor specifically needs a live query and approves the cost. | Do not present the proof source as a customer dimension or authoritative business history. |
| Cost / billing | [Cost and cleanup report](../../cloud/week7/closure/iam_cost_cleanup.md). | No billing screenshot is planned because settled charges and account-wide free-tier usage are unknown. | Never turn an estimate or an earlier zero period into a $0 bill claim. |
| Failure notification | [Redacted delivery receipt](../../cloud/week7/closure/notification_delivery_receipt.md). | Use the redacted historical receipt. | Do not show recipient address, inbox, notification channel, or incident data outside the retained redacted evidence. |

Keep all new captures outside the repository until reviewed for secrets and personal data. Do not create synthetic screenshots, manufacture application state, or edit receipts.

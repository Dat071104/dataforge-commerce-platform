## C4 gross list-price estimate

Rates were rechecked on 2026-11-15 from official Google Cloud pricing pages. For the full 120-hour authorization window, on-demand list rates, and no free-tier or credits:

| Resource | Calculation | Estimate |
|---|---:|---:|
| `e2-medium` VM | USD 0.03350571/hour × 120 hours | USD 4.021 |
| 30 GiB standard persistent disk | USD 0.000054795/GiB-hour × 30 × 120 | USD 0.197 |
| Cloud NAT gateway | USD 0.0014/instance-hour × 120 | USD 0.168 |
| One ephemeral NAT IP | USD 0.005/hour × 120 | USD 0.600 |
| **Known subtotal** | Before processed NAT traffic, outbound transfer, logs, or temporary storage | **USD 4.986** |

The VM compute component alone is USD 4.021. The USD 4.986 subtotal adds standard disk (USD 0.197), one-VM NAT uptime (USD 0.168), and one ephemeral NAT IP (USD 0.600). The C4 cap is USD 8, so the 80% stop threshold is USD 6.40; this fixed lower bound leaves USD 1.414 for variable usage. Cloud NAT processing is USD 0.045/GiB, internet egress to Asia is USD 0.12/GiB at the first paid tier (use USD 0.23/GiB as a conservative destination ceiling), and Cloud Logging is USD 0.50/GiB after the free allowance. A conditional envelope of 10 GiB NAT processing, 1 GiB internet egress, and 1 GiB logs over allowance adds at most USD 1.18, for an estimated USD 6.166 total. These usage ceilings are **modeled and not enforced by the Terraform module**; the image is not yet published or sized, so C4 still lacks an acceptable cost bound. Do not apply unless measured image/package sizes and a practical usage watchdog keep the estimate below USD 6.40. Official sources: [E2 VM pricing](https://cloud.google.com/products/compute/pricing/general-purpose?hl=en), [Persistent Disk pricing](https://cloud.google.com/compute/disks-image-pricing), [Cloud NAT pricing](https://cloud.google.com/nat/pricing), [Premium internet egress pricing](https://cloud.google.com/vpc/pricing), [Cloud Logging pricing](https://cloud.google.com/products/observability/pricing?hl=en).

## Scope

This portfolio combines Data Engineer Mini-projects 1 and 2: deterministic synthetic commerce ingestion, validation and Parquet Bronze; PostgreSQL raw/audit and Kimball marts; ten SQL analyses; and a local Power BI Desktop report. It is a local educational reference, not a production service, accounting system, or cloud deployment.

The canonical PBIP and related build/validator files were backed up locally before the accepted P6.2 visuals, KPI labels, text-only notes and builder/validator were promoted. The backup remains outside the repository. The public PBIP keeps `GoldWorkbookPath` set to `__DATAFORGE_LOCAL_WORKBOOK_PATH__`; regenerate the synthetic Gold workbook and configure the local path before opening or refreshing. Generated data, machine-specific paths and PBIP caches are not included.

## Limitations and roadmap

The fixture is synthetic; fulfilled sales is a proxy, not recognized revenue. The South RLS role is a demonstration, not production authorization. Facts retain separate grains; weather/shipment association is descriptive, not causal. Facts are full-rebuilt, not CDC. Official Microsoft PBIR schema validation and Desktop UI reopen from a relocated PBIP were not performed. No real retailer data, production SLA or cloud architecture is verified.

Potential GCP directions are functional mappings, not exact equivalents: Azure Data Lake Storage → Google Cloud Storage; Fabric Warehouse → BigQuery; batch execution → Cloud Run Jobs; scheduling → Cloud Scheduler / Workflows when needed; dbt → dbt-bigquery; Azure Key Vault → Secret Manager; Entra/RBAC → Google Cloud IAM; and infrastructure as code → Terraform. These are **planned**, not implemented or tested.

The Python package metadata remains `0.1.0`; `v1.0-local` is the portfolio repository release label, not a PyPI publication.

## Limitations and roadmap

The fixture is synthetic; fulfilled sales is a proxy, not recognized revenue. The South RLS role is a demonstration, not production authorization. Facts retain separate grains; weather/shipment association is descriptive, not causal. Facts are full-rebuilt, not CDC. Official Microsoft PBIR schema validation and Desktop UI reopen from a relocated PBIP were not performed. No real retailer data, production SLA or cloud architecture is verified.

Potential GCP directions are functional mappings, not exact equivalents: Azure Data Lake Storage â†’ Google Cloud Storage; Fabric Warehouse â†’ BigQuery; batch execution â†’ Cloud Run Jobs; scheduling â†’ Cloud Scheduler / Workflows when needed; dbt â†’ dbt-bigquery; Azure Key Vault â†’ Secret Manager; Entra/RBAC â†’ Google Cloud IAM; and infrastructure as code â†’ Terraform.
